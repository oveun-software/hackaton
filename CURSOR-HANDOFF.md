Las bases actuales exigen usar Cursor en el desarrollo. Esta primera versión se ha preparado en Codex desktop; no la presentéis como desarrollada en Cursor todavía.

1. Descarga Cursor desde su web oficial y abre `C:\Users\arian\Desktop\Proyectos\hackaton`.
2. Puedes usar su agente o instalar la extensión oficial **Codex** para Cursor e iniciar sesión. La [documentación oficial de OpenAI](https://learn.chatgpt.com/docs/codex/ide) incluye Cursor como editor compatible. El proyecto no requiere una API de OpenAI para ejecutar Nemotron.
3. Lee `README.md` y `HACKATHON.md`. Realiza una tarea de desarrollo real desde Cursor y documenta cómo se usó. Abrir la carpeta o hacer una captura por sí solo no acredita desarrollo.
